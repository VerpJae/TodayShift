# 오늘몇교대? (TodayShift)

장릉 오늘 가위바위보 결과는..??!!

오늘 담당 턴과 근무 시간을 확인할 수 있는 PWA 기반 웹 애플리케이션

## 📌 프로젝트 소개

오늘몇교대는 교대 근무자가 매일 자신의 근무 순서와 시간을 빠르게 확인할 수 있도록 제작한 모바일 중심 웹 앱입니다.

근무 인원 수에 따라 달라지는 교대 시간표를 선택하고, 자신의 담당 턴을 표시하여 오늘 근무 시간을 쉽게 확인할 수 있습니다.

---

## ✨ 주요 기능

### 현재 구현

- 근무 인원 설정
  - 1명 ~ 4명 근무 선택

- 담당 턴 설정
  - 내 담당 턴 선택
  - 선택한 턴 강조 표시

- 교대 시간표 표시
  - 근무 시간 표시
  - 휴게 시간 표시

- 모바일 대응 UI
  - 모바일 화면 최적화
  - PWA 구조 적용


### 예정 기능

- iOS Push Notification 지원
- 근무 시작 전 알림
- 사용자 설정 저장
